# hSVMS Dashboard

Dashboard project + design system showcase.

## 結構

- `tokens.css` — Design tokens（字級 + 色彩，含 light / dark 雙模式）
- `index.html` — 設計系統視覺展示頁

## 預覽方式

直接用瀏覽器打開 `index.html` 即可。

## 設計系統

- **字型**：Noto Sans TC（思源黑體）
- **字級**：15 種（Head1 → Body5，三種字重）
- **色票**：29 個語意色 token，全部支援 light / dark
